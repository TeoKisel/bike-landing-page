# MyBike

MyBike is a responsive landing page for a bicycle brand. The project focuses on clean design, responsive layouts, and a convenient user experience across different screen sizes.

## Live Preview

- [DEMO LINK](https://TeoKisel.github.io/bike-landing-page/)

## Technologies Used

- HTML5
- SCSS (Sass)
- ESLint
- BEM methodology

## Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone (GitHub repository URL)
cd (name of your folder)
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run the project

```bash
npm start
```

The development server should start, and the project will be available at the local address shown in the terminal.

### 4. Check the code with ESLint

```bash
npm run lint
```

Make sure the commands above match the scripts defined in your `package.json`.
